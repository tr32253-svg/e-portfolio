# E-Portfolio สำหรับครูเทคโนโลยีและการเขียนโปรแกรม

เว็บไซต์ E-Portfolio แบบหน้าเดียวสำหรับแสดงประวัติผลงาน กิจกรรม และข้อมูลติดต่อของครูผู้สอนด้านเทคโนโลยีและการเขียนโปรแกรม

## คุณสมบัติ

- เว็บไซต์ 4 ส่วน: หน้าแรก, แนะนำตัว, ผลงาน และกิจกรรม
- ธีมสีน้ำเงิน-ขาวสวยงามและอ่านง่าย
- ฟอนต์ Prompt รองรับการแสดงผลภาษาไทย
- เมนูนำทางแบบ Responsive และเมนูมือถือ
- รายการผลงานพร้อมชื่อ คำอธิบาย และลิงก์ GitHub
- ส่วนท้ายสำหรับข้อมูลติดต่อ
- รองรับการแสดงผลบนคอมพิวเตอร์และโทรศัพท์มือถือ

## เทคโนโลยีที่ใช้

- HTML5
- CSS3
- JavaScript
- Google Fonts — Prompt

## โครงสร้างไฟล์

```text
index.html  เว็บไซต์ทั้งหมดในไฟล์เดียว
README.md   เอกสารการใช้งาน
```

## วิธีเปิดดูบนเครื่อง

1. ดาวน์โหลดหรือ Clone Repository:

```bash
git clone https://github.com/tr32253-svg/e-portfolio.git
```

2. เข้าโฟลเดอร์โปรเจกต์:

```bash
cd e-portfolio
```

3. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ หรือใช้ส่วนขยาย Live Server ใน VS Code

## การแก้ไขข้อมูล

แก้ไขเนื้อหาในไฟล์ `index.html` ได้ตามตำแหน่งต่อไปนี้:

- ชื่อผู้สอนและประวัติ: ส่วน `id="about"`
- ผลงาน: ส่วน `id="projects"`
- กิจกรรม: ส่วน `id="activities"`
- ลิงก์ GitHub และอีเมล: ภายในเมนูและส่วนท้ายเว็บไซต์

ควรเปลี่ยนข้อมูลตัวอย่างให้เป็นข้อมูลจริงก่อนเผยแพร่สาธารณะ

## การเผยแพร่ด้วย GitHub Pages

1. เปิด Repository บน GitHub
2. ไปที่ **Settings → Pages**
3. ที่ **Build and deployment**, เลือก **Source: Deploy from a branch**
4. เลือก Branch `main` และโฟลเดอร์ `/ (root)`
5. กด **Save**

เมื่อดำเนินการเสร็จ เว็บไซต์จะเผยแพร่ที่:

```text
https://tr32253-svg.github.io/e-portfolio/
```

GitHub Pages อาจต้องใช้เวลาสักครู่ในการสร้างและเผยแพร่เว็บไซต์ครั้งแรก
